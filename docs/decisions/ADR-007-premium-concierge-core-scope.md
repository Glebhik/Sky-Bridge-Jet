# ADR-007: Premium concierge as core, scope-controlled capability

## Status

Accepted — Product Owner Approved

## Context

The product must serve high-net-worth private-aviation journeys rather than
becoming only a flight-search interface.

## Decision

Treat concierge as a core product direction. Model trip requirements and
extensible provider boundaries for ground transport, FBO coordination, catering,
pets, baggage, special assistance, preferences, and destination services.
Implement only what is necessary for the private-jet booking journey in V1.

## Consequences

The domain supports premium journey coordination without creating a large
general-purpose concierge platform or overextending V1 scope.

## Deferred / Requires Specialist Review

Third-party service contracts, data sharing, insurance, local regulations, and
fulfilment obligations require appropriate specialist review.
